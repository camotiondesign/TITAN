# Titan Caption Writing Playbook

## The Principle

Don't rely on one caption formula.

Most B2B captions follow:

> Statement → Explanation → More explanation → CTA

Instead, vary the psychological entry point. The hook determines the
entire post.

------------------------------------------------------------------------

# Caption Body Structures

  Structure                               Flow
  --------------------------------------- ----------------------
  Problem → Solution → Outcome            Classic case study
  Story → Lesson → CTA                    Founder content
  Observation → Explanation → Takeaway    Thought leadership
  Quote → Context → Why it matters        Customer videos
  Before → Change → After                 Transformations
  Myth → Reality → Evidence               Educational
  Question → Answer → Proof               Explainer
  Statistic → Interpretation → Insight    Data-led
  Challenge → Journey → Result            Narrative
  Scene → Conflict → Resolution           Documentary
  Pain → Hope → Proof                     Emotional
  Past → Present → Future                 Vision
  One Idea → Three Examples → CTA         Carousel
  Hero → Obstacle → Win                   Customer spotlight
  Trend → Opinion → Prediction            Industry commentary
  Contrarian → Evidence → Reframe         Engagement
  Mini Story → Quote → Reflection         Personal
  Customer Voice → Analysis → Lesson      Testimonial
  Framework → Explanation → Application   Educational
  Observation → Principle → Invitation    Conversation starter

------------------------------------------------------------------------

# How to Use

Choose:

1.  One hook structure.
2.  One body structure.
3.  One story.

40 hook structures × 20 body structures = **800 unique caption
combinations** before changing the topic.
